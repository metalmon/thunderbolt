# Общая модель контура: набор моделей и полоса управляемого апстрима

Памятка для того, кто ставит пилот. Отвечает на один вопрос: **откуда клиент
берёт список моделей и как он попадает к модели, не зная ключа.**

Без этих записей пилот работает, но каждый пользователь видит каталог моделей
из сборки клиента и должен сам вводить ключ в настройках. Нам нужно обратное:
один набор на весь контур, ключ — только на сервере.

## Две записи, которые всё решают

| Запись | Что делает |
| --- | --- |
| `DEFAULT_MODELS` | набор моделей, который бэкенд раздаёт всем клиентам |
| `MANAGED_UPSTREAM_BASE_URL` + `MANAGED_UPSTREAM_API_KEYS` | куда и с каким ключом бэкенд ходит за ответом модели |

Обе живут в `backend/.env`. Примеры с пояснениями — в `conf/.env.example`,
строки 170–200.

### Набор моделей

```
DEFAULT_MODELS=[{"id":"<uuid>","name":"Локальная модель","provider":"openrouter","model":"Qwen3.6-35B-A3B-AWQ","contextWindow":32768,"vendor":"qwen","description":"Модель контура"}]
```

Обязательны `id`, `name`, `provider`, `model`; остальное достраивается
(`isSystem`, `enabled`, `toolUsage` = 1).

- `provider: "openrouter"` — **ключ остаётся на сервере**: клиент идёт через
  полосу управляемого апстрима и ключа не видит. Это наш случай.
- `provider: "custom"` — клиент обращается к `url` напрямую, а ключ вводит
  человек. Для закрытого контура не годится.

⚠ `toolUsage` обязан быть `1`, иначе агент не сможет вызывать инструменты — а
без инструментов не работают и веб-панели.

### Версия набора

`DEFAULT_MODELS_VERSION` можно **не задавать**: тогда она считается как «версия
сборки плюс один» и всегда выигрывает у набора, вшитого в клиент.

Задавать руками нужно ровно в одном случае: набор **меняется**, а устройства уже
применили прежний. Им нужен строго больший номер, иначе изменение до них не
доедет — согласование между устройствами держится на возрастании номера.

⚠ Откат делается **повышением** версии с прежним содержимым. Никогда понижением:
устройство, уже применившее больший номер, меньший игнорирует.

### Полоса управляемого апстрима

```
MANAGED_UPSTREAM_BASE_URL=https://llm.example.local/v1
MANAGED_UPSTREAM_API_KEYS=<ключ или несколько через запятую>
MANAGED_UPSTREAM_RPM=10
```

Нужна только моделям с `provider: "openrouter"`. Имя историческое: апстримом
может быть любой OpenAI-совместимый шлюз контура. Прежние имена `OPENROUTER_*`
продолжают читаться как запасные.

`MANAGED_UPSTREAM_RPM` — потолок запросов в минуту на пользователя.

## Грабли, на которых уже стояли

⚠ **Клиент всегда шлёт `tool_choice: "auto"`.** Это умолчание ядра AI SDK, снять
его с клиента нельзя. Упрощённые шлюзы на незнакомом поле падают с 400. Если
апстрим контура — самодельный шлюз, он обязан либо понимать это поле, либо
выбрасывать его у себя на входе. Проверяется одним запросом: добавьте
`"tool_choice":"auto"` в обычный запрос к апстриму и посмотрите, отвечает ли он.

⚠ **Настройки читаются один раз за запуск процесса.** После правки `.env`
бэкенд надо перезапустить: `docker compose restart backend`.

⚠ **Набор раздаётся, а не навязывается.** Устройство, у которого уже применён
набор с большим номером версии, новый с меньшим проигнорирует — см. раздел про
версию выше.

## Проверка

1. `docker compose restart backend`, затем в журнале бэкенда:
   `[models] Publishing deployment set: version <N>, <M> row(s)` — значит набор
   принят и раздаётся.
2. `curl -sk https://<адрес>/v1/config | grep -o '"models"' ` — набор приезжает
   в составе настроек клиента.
3. Войти в Вольт: в выборе модели над полем ввода стоит модель из набора, а в
   настройках у неё **нет** поля для ключа (ключ на сервере).
4. Отправить любой вопрос — ответ пришёл, в настройках ключ так и не
   потребовался.

## Если не работает

| Что видно | Что это значит |
| --- | --- |
| В выборе модели пусто или модели из сборки | `DEFAULT_MODELS` не прочитан: не перезапущен бэкенд либо в строке не разобрался JSON |
| Модель есть, но ответа нет, в журнале 401/403 от апстрима | `MANAGED_UPSTREAM_API_KEYS` пуст или ключ не тот |
| Апстрим отвечает 400 на любой запрос | скорее всего `tool_choice` — см. грабли выше |
| Агент отвечает словами, но не вызывает инструменты | у модели `toolUsage` не 1 |
| Поменяли набор, а на устройствах старый | нужен строго больший `DEFAULT_MODELS_VERSION` |

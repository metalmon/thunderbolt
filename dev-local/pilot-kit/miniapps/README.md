# Мини-приложения поставки

Состав объявлен в `volt.toml`, разделом `[[miniapps]]`. Архивы образов лежат в
`miniapps/images/`.

Добавить панель:

1. положить архив образа в `miniapps/images/`;
2. дописать блок `[[miniapps]]` в `volt.toml` (id, название, образ, имя образа
   внутри архива, порт);
3. запустить установщик и отметить панель в разделе «Мини-приложения».

Наложение compose и блоки слушателей nginx установщик пишет сам, в
`backend/docker-compose.miniapps.yml` и `backend/conf/nginx/miniapps-<id>.conf.template`.
Править их руками незачем: при следующем применении они будут перезаписаны.

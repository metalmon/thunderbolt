# Автономный режим: перечень обращений к бэкенду

Документ ведётся вместе с проверкой `src/fork/local-mode/backend-callers.test.ts`.
Проверка держит список файлов, способных обратиться к нашему бэкенду. Появился
новый — набор становится красным, и тот, кто его добавил, записывает сюда ответ
на один вопрос: **что это делает на установке, у которой сервера нет?**

Редакция от 30.10.2026. База форка 9f3db1379.

## 1. Зачем документ

Спека автономного режима уже называла полосы, которые обязаны исчезнуть. Тем не
менее в выпуск 0.1.148 уехали шесть течей: полоса «Volt Pro», перечень
mini apps, поиск владельца агентов, голосовой движок на нашем хостинге, имя
продукта и карточка «Данные». У всех шести одна форма:

> решение, принятое **на сборке** или **в серверном режиме**, подставлено
> вместо решения времени выполнения.

Спека, которую никто не обязан открыть, — не предохранитель. Предохранитель —
перечень, который краснеет сам.

## 2. Правило

**Выключается полоса, идущая через наш бэкенд, а не возможность.** Модель со
своим ключом работает; полоса `managed` — нет. Голос через совместимый с OpenAI
адрес работает; голос через `/v1/audio/*` — нет. Погода работает: она ходит в
open-meteo напрямую и нашего бэкенда не касается.

## 3. Три допустимых ответа

| Ответ                | Значение                                                                 |
| -------------------- | ------------------------------------------------------------------------ |
| **закрыт**           | отказывает в автономном режиме явно, через `isLocalMode()`               |
| **мертв без сеанса** | не может выстрелить: нужен сеанс, которого в автономном режиме не бывает |
| **разрешён**         | через наш бэкенд не идёт вовсе (свой адрес пользователя)                 |

Четвёртого ответа нет. «Вроде бы не вызывается» — это **течь**, пока не доказано
одно из трёх.

## 5. Как поддерживать

1. Добавили обращение к бэкенду — набор краснеет на
   `src/fork/local-mode/backend-callers.test.ts`.
2. Вписали файл в список проверки **и** строку сюда, в раздел 4.1, 4.2 или 4.3.
3. Если ответ «закрыт» — закрывайте через `isLocalMode()`/`useIsLocalMode()` из
   `src/fork/local-mode/mode.ts` и оставляйте сторож, который краснеет без него.

⚠ Образец обращения в проверке принимает и `authClient?.`, и `authClient.`:
необязательный вызов — это ровно то, чем поиск владельца агентов уходил на
сервер, и более строгий образец его не видел.
